# ПОБЕДА — календарь побед

Тёмный минимализм и агрессивная мотивация. Отмечай дни побед, держи серию, получай звания и награды. Данные живут только у тебя — никаких серверов и аккаунтов.

## Возможности

- 🌍 **Два языка** — Русский / English (переключатель в настройках; английская версия — на живом сленге, а не «перевод с русского»)
- 📅 **Календарь месяца** — дни побед подсвечиваются цветами категорий, клик по дню = отметить/изменить
- 🏷️ **Свои категории** — название, эмодзи, цвет (учёба, спорт, что угодно)
- 🏁 **Логическое завершение целей** — когда курс/программа закончены, жми «✔» у цели, опиши причину («закончил курсы») — цель уйдёт в «Завершённые» с историей: даты, дней отмечено, рекорд. Это не провал: серию не ломает, счётчик срывов не трогает. Можно вернуть в строй одной кнопкой
- 📢 **Скриншот-хвастство** — кнопка «Похвастаться» рисует карточку 1080×1350 с серией, званием, рекордом и нахальной фразой («Я 300 дней в серии. А ты сколько?»). На айфоне откроется системный шеринг → «Сохранить изображение» → фото падает в галерею. На компьютере — скачивается PNG
- 🔥 **Ежедневная серия** — общая + отдельная по каждой категории (с льготой: если сегодня ещё не отмечено, серия не сгорает до конца дня)
- ❄ **Заморозка серии** — пропустил вчера? Жми большую красную кнопку **«Я — ЛОШАРА»**: признаёшь позор — серия спасается. +1 заморозка за каждую закрытую неделю, максимум 3 в запасе
- 📊 **Статистика** — победы за 30 дней, загрузка месяца, бары по 12 неделям, профиль по дням недели («твой слабый день»), разбивка по категориям
- 🎖️ **Звания** за серию: Новобранец → Разогрев → Железная неделя → Хищник → Машина → Неудержимый → Легенда → Титан → Бессмертный
- 🏆 **Зал наград**: 7 / 14 / 30 / 60 / 100 / 200 / 365 дней
- 🔒 **Секретные награды** после 365 дней (400 / 500 / 730 / 1000 / 2000) — в списке не видны вовсе; узнаешь о них только получив
- 🔔 **Локальные напоминания** — если к заданному времени день не отмечен, приложение уведомит (пока вкладка/приложение открыто; у установленного PWA — даже когда окно закрыто)
- 💾 **Экспорт/импорт** данных в JSON, офлайн-режим (service worker)

## Запуск на ноутбуке

**Быстрый старт:** просто открой `index.html` двойным кликом в Chrome/Edge. Всё работает, включая уведомления.

**Полный режим (установка как приложение + офлайн):** нужен локальный сервер, любой из вариантов:

```powershell
# если установлен Node.js
npx --yes serve .

# если установлен Python
python -m http.server 8000
```

Открой `http://localhost:8000` (или порт из вывода) → в адресной строке Chrome/Edge появится значок **«Установить приложение»**. После установки «ПОБЕДА» запускается как отдельная программа с собственной иконкой.

## Установка на iPhone

1. Выложи папку на любой HTTPS-хостинг (GitHub Pages, Netlify, Vercel — бесплатно) или открой по локальной сети.
2. В Safari открой сайт → **Поделиться → «На экран “Домой”»**.
3. Иконка на рабочем столе, запуск в полноэкранном режиме, данные в localStorage.
4. Уведомления: только iOS 16.4+ и только с сервером — поэтому в приложении они работают, пока оно открыто.

> ⚠️ Данные хранятся в браузере. Очистка данных сайта = потеря серии. Пользуйся «Экспорт данных» в настройках.
